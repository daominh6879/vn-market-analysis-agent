Data Collection

Three distinct source groups, each with its own ingestion path and schedule. PDF reports trigger Dagster on MinIO upload; news and market data run on cron schedules.

PDF / BCTC Reports Event-driven
  • PDF files uploaded to MinIO buckets hpg-docs vcb-docs fpt-docs
  • Dagster sensor minio_new_pdf_sensor polls every 5 min via ETags → triggers ingestion_job
  • Deleted PDF → delete_job soft-deletes from Qdrant + Postgres
  • 3 parsers: pymupdf4llm (primary, Tesseract OCR vie+eng), pdfminer (fast), LlamaParse (cloud, requires API key)
  • → Feeds PROCESS pipeline below
News Articles Every 6h
  • CafeF RSS + VnExpress RSS — scrape full article body
  • FireAnt API (restv2.fireant.vn, type=1) — per-ticker posts for all VN30 tickers
  • CafeF per-ticker — search endpoint, up to 15 articles/ticker
  • Dedup: ON CONFLICT (url) DO NOTHING
  • Ticker tagging via regex on title + body (no LLM)
  • → news_articles table + news_chunks Qdrant collection
Market & Financial Data Daily / Monthly
  • vnstock financials — annual BCTC via VCI source → financial_facts (1st/month 01:00)
  • Stock prices — daily close via vnstock → stock_prices (weekdays 18:00)
  • OHLCV — VN30 + index candles via VciDirectProvider → ohlcv_daily
  • Market indices — VNINDEX/HNX/UPCOM/VN30/HNX30 via SSI iBoard → market_index_daily
  • Foreign flows — per-ticker net buy/sell → foreign_flows
  • Corporate events — dividends, rights, AGM → corporate_events
  • Global quotes — world indices, commodities, crypto, FX, VN gold → market_quotes

Hybrid Retrieval Augmentations
  • BM25 — loads all Qdrant chunks in memory, builds BM25Okapi index; Vietnamese tokenization via underthesea
  • Multi-query — LLM reformulates question into N variants, retrieves each, deduplicates
  • Cross-encoder reranker — reranks top candidates from vector search
  • Fusion — weighted sum (alpha blend, both scores normalized to [0,1]) or RRF (k=60)
SQL Agent Path
  • LLM router classifies query: diễn_giải → RAG only; số_liệu → SQL only; cả_hai → both; ngoài_phạm_vi → refusal
  • SQL agent generates query → executes against Postgres: financial_facts stock_prices ohlcv_daily
  • Structured numbers come from Postgres; narrative explanations come from Qdrant RAG
Store

Storage Systems

Three complementary stores: MinIO holds raw files, Qdrant holds semantic vectors, Postgres holds structured relational data. Redis is the exact-match cache tier; Qdrant cache_vectors is the vector similarity tier — both wired into turn_handler.py as of Bài 32.

Object storage · port 9000
Raw PDF buckets
One bucket per ticker: hpg-docs vcb-docs fpt-docs. Polled by Dagster sensor via ETags every 5 min.
Parsed Markdown

⚡
Qdrant
Vector DB · port 6333 · cosine
bctc_structural
BCTC PDF chunks, bge-m3 1024-dim. Payload: ticker, sector, year, report_type, source_key, doc_id. Idempotent via SHA-256 doc_id + UUID5 chunk_id. Old chunks purged by source_uri before re-index.
news_chunks
News article embeddings. Payload: title, source, published_at, tickers, url. Filtered by DatetimeRange + ticker MatchAny. Purged >90 days weekly.
episodic_memory
Conversation episode summaries per user. Scored with exponential decay: score × exp(−days/30). Hard expiry 90 days. Top-3 retrieved on session start.
cache_vectors · Bài 32
Tier-2 vector cache. Each point: embed(normalized_question), payload {ticker, tenant_id, prompt_version, model_version, reply, expires_at}. Ticker guard prevents HPG/HSG cross-hit. Threshold cosine ≥ 0.92.
Tenant isolation
  • tenant_id payload field + Qdrant Filter at query time — never post-filter

Redis · 2-tier Response Cache Active · Bài 32
  • Tier 1 — Exact: SHA-256(CacheKey JSON) → key cache:b32:exact:{hash}. Hit = guaranteed correct. TTL: 120s market hours (Mon-Fri 09:00–14:45 VN), 1800s otherwise.
  • Tier 2 — Vector: embed(normalized_question) → Qdrant cache_vectors, cosine ≥ 0.92. Ticker guard + tenant guard + expires_at check before returning.
  • CacheKey: tenant_id ticker normalized_question prompt_version model_version — no conversation_id, cache is cross-conversation.
  • Skip condition: len(history) > 0 → turn 2+ never cached; make_cache_key() returns None.
  • Wired in memory/turn_handler.py — both run_turn and stream_turn. Cache hit emits SSE event: status step=cache_hit tier=exact|vector.
  • Fail-safe: all Redis/Qdrant errors caught silently → graceful miss, agent runs normally.
Retrieve & Use

Retrieval & Agent Layer

Query enters a fast keyword router (no LLM, <1ms). Router picks one of 9 intents, dispatches to the right tool(s). LangGraph orchestrates multi-step analysis. Memory system maintains context across sessions.

Query Router <1ms · no LLM
Fast keyword classifier. Falls back to LLM router on uncertain cases.
price_action technical_analysis fundamentals macro_sector news_sentiment screening market_brief investment_case conversation
Retrieval Methods 22 tools
  • BCTC RAG — embed query → Qdrant bctc_structural, top-5, payload filters (ticker, sector, year) → LLM synthesize
  • News Search — embed → Qdrant news_chunks, DatetimeRange 30d default, optional ticker MatchAny
  • SQL Agent — LLM generates SQL → executes on financial_facts ohlcv_daily etc.
  • Market tools — direct Postgres queries for OHLCV, indices, foreign flows, events, global quotes
  • Hybrid classifier — diễn_giải / số_liệu / cả_hai / ngoài_phạm_vi
LangGraph Agent 4-node graph
collect → analyze_technical → assess_risk → synthesize
  • collect — parallel fetch OHLCV (VCI API) + news; cache CSV to outputs/agent_cache/
  • analyze_technical — read CSV → calculate_indicators
  • assess_risk — if/else on 14-session return std; low vol → call analyze_market_sentiment
  • synthesize — LLM → Markdown report (technical, risk, news, sentiment sections)
  • Checkpoints via PostgresCheckpointer → lg_checkpoints tables. Human-in-the-loop: pause → agent_sessions (5-min TTL) → approval API → resume
Memory System 4 layers
conv Last 10 turns from messages table. Written after each turn.
user LLM-extracted preferences via memory/extractor.py → user_memory table (key/value, confidence, superseded chain).
episodic Session summary embedded → Qdrant episodic_memory. Top-3 past episodes on session start. Decay: score × exp(−days/30). 90d hard expiry.
procedural System prompt customization rules. Applied at LLM call construction.
LLM Providers Pluggable via .env
All calls go through llm/factory.py → create_client(). Switch by setting LLM_PROVIDER.
  • deepseek — default provider
  • anthropic — Claude models
  • openai — GPT models
  • gemini — Google Gemini
  • ollama — local models (localhost:11434)
  • Optional: Langfuse tracing wrapper on all calls
Planner DAG executor
  • LLM generates JSON Plan — list of Step objects with executor (tool name) + depends_on DAG
  • Validation: no cycles, all executors in 22-tool registry, ≤10 steps, ≤20k token budget
  • Retries once on fail, then falls back to default_plan
  • Steps execute in topological order honoring depends_on
